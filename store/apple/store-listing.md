# Метаданные для Apple App Store — «Дни Минувшие: Осада»

## Важно: техническое ограничение

Сборка `.ipa` требует **macOS + Xcode** (или облачного CI на macOS).
Из Windows `.ipa` собрать нельзя физически. Варианты:

1. **Mac в аренду** (MacinCloud, MacStadium) — залить проект, собрать Xcode.
2. **Облачный CI** (Codemagic, Bitrise) — подключить репозиторий, собрать удалённо.
3. **Xcode Cloud** — если есть Mac для первичной настройки.

Всё, что можно подготовить без Mac, — подготовлено здесь:
метаданные, скриншоты всех размеров, иконки, конфиги и инструкция по сборке.

## Внутренние покупки (App Store Connect → In-App Purchases)

Создать с теми же ID, что и в Google Play:

| Product ID | Тип | Название | Цена |
|---|---|---|---|
| `gold_small` | Consumable | Горсть золота | 99 ₽ |
| `gold_mid` | Consumable | Мешок золота | 399 ₽ |
| `gold_big` | Consumable | Сундук золота | 1 790 ₽ |
| `starter` | Non-Consumable | Набор новобранца | 599 ₽ |
| `vip` | Non-Consumable | Статус Хранителя | 1 990 ₽ |
| `noads` | Non-Consumable | Без рекламы | 499 ₽ |

потому что Apple требует, чтобы цена покрывала комиссию.

## Что сделать на Mac (пошагово)

```bash
# 1. Установить Xcode + command line tools
xcode-select --install

# 2. Создать проект-обёртку (WKWebView)
#    File → New → Project → App → Interface: SwiftUI, Language: Swift
#    Bundle ID: com.tommlee.daysbygone

# 3. Скопировать game/ в проект:
#    добавить папку game в target (Create folder references, НЕ groups)

# 4. Заменить ContentView.swift содержимым store/apple/ContentView.swift

# 5. Info.plist: UISupportedInterfaceOrientations = LandscapeLeft, LandscapeRight
#    UIRequiresFullScreen = YES

# 6. Добавить StoreKit 2 для покупок и Google Mobile Ads SDK (или AdMob через SPM)

# 7. Собрать Archive → Distribute App → App Store Connect
```

## Важно про рекламу на iOS

AdMob SDK для iOS подключается иначе (Swift Package Manager).
Логика игры та же — мост `window.Android` нужно переименовать в `window.ios`
или сделать универсальный: в `monetization.js` заменить проверку `window.Android`
на `window.Android || window.ios`.
