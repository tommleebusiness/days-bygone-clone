Заполнить в консоли:

- **Адрес электронной почты:** нет
- **Идентификаторы устройства:** да — AdMob ID (для рекламы)
- **Данные о действиях в приложении:** нет

## Реклама (AdMob)

1. Создать аккаунт AdMob → добавить приложение.
2. Заменить три ID:
   - app id → `android/app/src/main/AndroidManifest.xml` (`com.google.android.gms.ads.APPLICATION_ID`)
   - banner → `AdsManager.java` (`UNIT_BANNER`)
   - interstitial → `AdsManager.java` (`UNIT_INTERSTITIAL`)
   - rewarded → `AdsManager.java` (`UNIT_REWARDED`)
3. В консоли AdMob настроить `app-ads.txt` на домене (для максимальной доходности).
