# Дни Минувшие — Осада

Пиксельный клон **Days Bygone** — оборона средневекового замка. Всё нарисовано кодом
(без картинок), эффекты на [pixelfx](https://github.com/patch-gg/pixelfx).

## Что внутри

- **Мир 640×360** — мелкий пиксель, сцена вписывается в экран без обрезки
- **Лучник-герой** с плавной анимацией натяжения лука, отдачей и аурами от экипировки
- **8 оборонительных сооружений** с прокачкой и визуальными апгрейдами (5 уровней):
  катапульта, баллиста, котёл масла, башня лучников, башня мага, шипы, арбалетная башня, лагерь лекаря
- **Экипировка в стиле Diablo 2**: кукла героя + 10 слотов + сетка инвентаря, описания предметов
- **6 редкостей** от базового до легендарного — редкие и легендарные предметы меняют вид героя
  (золотые доспехи, аура, плюмаж, золотой лук)
- **Погода**: дождь, снег, гроза с молниями, туман; солнце с лучами, облака
- **Ландшафт**: анимированные дубы и ели, кусты, трава, птицы, падающие листья
- **Дерево навыков**: 3 ветки × 4 узла

## Играть

Откройте `days-bygone-clone/game/index.html` в браузере или поднимите локальный сервер:

```bash
cd days-bygone-clone/game
python -m http.server 8619
# http://localhost:8619/
```

## Android

Готовый APK: `days-bygone-clone/android/app/build/outputs/apk/release/app-release.apk`

Сборка:

```bash
cd days-bygone-clone/android
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleRelease
```

Приложение — WebView-обёртка, игра работает офлайн из `assets/game/`.

## Управление

| Действие | Как |
|---|---|
| Магазин | нижняя панель, тап по карточке |
| Экипировка | кнопка 🎒 в HUD |
| Навыки | кнопка 🌳 в HUD |
| Фулскрин | ⛶ или клавиша F |
| Инвентарь | тап по предмету — описание, двойной тап — надеть |
